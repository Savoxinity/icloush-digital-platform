# 网站打磨与商城陈列审阅记录

## 当前正面基础

当前前台已经具备多品牌入口、黑场展柜、商品详情、购物袋、外部渠道桥接和详情长图能力，因此不是从零开始，而是进入“产品化打磨”阶段。

## 影响上线陈列感的主要问题

| 模块 | 当前表现 | 主要问题 |
| --- | --- | --- |
| 根路径平台首页 | 已能展示五个站点入口与平台说明 | 首屏偏“项目总览”，更像内部导航页，不像对外官网首页；缺少主品牌叙事、精选商品/场景、明确商城主 CTA |
| `/shop` 商城页 | 已有目录式对象列表、筛选、预览和加袋 | 命名仍偏“Object Index / Silent Catalogue”，对普通客户不够直观；缺少精选货架、上新/热卖/场景化分组、品牌承诺与服务说明 |
| `/object/:id` 商品详情 | 已有主视觉、实验面板、长图详情、外部渠道和下单区 | 商详页信息重心仍偏“实验档案”，成交信息不足；缺少购买理由、适用场景、服务承诺、发货/售后/使用建议等电商化陈列信息 |
| 全站 SEO / 标签 | 仍沿用 LAB Retail Gallery | 浏览器标题、描述和分享文案仍是旧 LAB 语义，与当前多品牌数字平台定位不符 |
| 入口与动线 | 已有 `/astro`、`/tech`、`/lab`、`/shop` 多入口 | 根路径到商城的主导动作不够强，商城与品牌站点之间缺少“从品牌内容直接进入商品陈列”的连续动线 |

## 本轮优先打磨方向

1. 把根路径从“站点索引页”升级为“品牌生态官网首页”。
2. 把 `/shop` 从“实验名录”升级为“可线上上架陈列的商城首页/展柜页”。
3. 把 `/object/:id` 从“实验档案页”升级为“兼具品牌感与成交感的商品详情页”。
4. 同步修正 `index.html` 的标题、描述和分享元信息，使其对应多品牌数字平台与商城陈列定位。

## 本轮核验后的最新状态

### 已确认改善

当前根路径已经明显从“内部站点索引页”升级为 **iCloush 多品牌官网总入口**：首屏具备更明确的生态叙事、平台能力卡片、精选商品对象与多品牌站点入口。`/shop` 也已形成更接近线上货架的首页结构，`/object/:id` 则已经具备购买理由、陈列打法、服务面板与渠道桥接，能够承接对外演示和初步咨询转化。

### 仍需继续修正的重点

1. **首页主 CTA 文字可见性仍偏弱。** 浏览器可识别“进入商城陈列页”“查看浣星司 / ASTRO”文本，但真实截图里两枚深色按钮的字仍显得过暗，视觉上接近黑底黑字，后续需要继续提高前景对比度与按钮文本权重。
2. **商城页仍偏“对象目录”而非成熟商城。** 当前货架结构已成型，但还可以继续补强主推商品权重、分类可读性、服务信号和更强的成交导向。
3. **商品详情页的真实成交信息仍可继续增强。** 当前已具备说服式结构，但如果要更接近正式商城 PDP，仍建议继续补发货/售后/使用建议与更多详情长图沉浸感。

## 2026-05-12 浣星司 `/astro` 展示承接补充核验

本轮新增的 **Concept Mounts** 与 **Product Landing Hooks** 已在真实预览中正常渲染，页面现在不再只是黑场品牌占位页，而是开始具备从图像展厅过渡到商品陈列的承接能力。顶部展陈叙事、概念挂载位说明与三个落地页入口（商品详情示例、深色礼赠示例、商城陈列层）已经形成一条更完整的浏览动线。

从当前预览看，`/astro` 的视觉基调仍与黑场 scroll-snap 展厅保持一致，没有被新的承接模块破坏整体审美。后续如果继续深化，可优先补两类内容：其一是把三组挂载位替换为真实的浣星司商品图与概念图；其二是把落地页入口进一步映射到专属的 ASTRO 商品详情，而不只是先借用统一商城中的示例商品页。

## 2026-05-12 `/shop` 货架页补充核验

当前商城首页已经具备更像统一货架的上半屏：首屏能同时说明在线陈列对象数量、上架结构和当前主推商品，用户进入后能迅速理解这里不是单纯内部目录，而是第一批可线上陈列商品的公开入口。主推商品卡和系列筛选也已经能把空气净域与织物护理两条线分开呈现。

不过，下半屏的浏览体验仍然保留了较重的 “Object Index / Silent Catalogue” 目录语气，普通消费者仍会更容易把它理解成设计化名录，而不是成熟商城货架。后续如果继续打磨，可优先补两点：其一是把“Objects”语义进一步改造成更直白的“精选商品/系列货架”；其二是在卡片与筛选区强化“上新、热卖、适用场景、服务承诺”等更接近零售陈列的话语。
